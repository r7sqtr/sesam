# sesam
macOS用のファイルマネージャ
グローバルホットキー（既定 `Ctrl+P`）で、どの Space・全画面アプリの上にいてもパネルが即座に出現する Finder 代替アプリ

- バンドル ID: `com.r7sqtr.sesam`
- スタック: Tauri 2（Rust）+ React + TypeScript + Vite + Zustand
- 対象 OS: macOS（メニューバー常駐、Dock 非表示）

## 主な機能
- **呼び出し／常駐**: グローバルホットキーでトグル表示
- **閲覧**: 単一リスト⇔2 ペイン切替、タブ、仮想スクロール、フィルタ、名前/更新日時/サイズでのソート、隠しファイル表示切替
- **操作**: コピー/移動（衝突ダイアログ・進捗・キャンセル対応）、ゴミ箱、リネーム、新規フォルダ、zip 圧縮/展開、取り消し・やり直し（リネーム/新規フォルダ/移動/コピー）
- **ドラッグ&ドロップ**: アプリ内、Finderや他アプリとの間でも可能
- **プレビュー**: 画像・動画・音声・PDF・Markdown・HTML・ソースコード（シンタックスハイライト）
- **検索/ジャンプ**: ホーム配下のファジー検索（frecency + 全体インデックス）、パス直接入力（Tab 補完）、ブックマーク
- **カスタマイズ**: ホットキー、キーマップ（Vim / 標準の 2 プリセット + 個別上書き）、ホームの場所、背景の透明度

## キーマップ

2 種類のプリセットを設定画面で切り替えられます。個別のキー割り当ても上書きできます。

- **Vim**: `hjkl` 移動、`gg`/`G`、`y`/`d`/`p`（ヤンク/カット/ペースト）、`t`（ゴミ箱）、`x`（カット/ヤンク取消）、`a`（新規フォルダ）、`r`（リネーム）、`z`（圧縮）、`/`（フィルタ）、`f`（検索）、`\`（2 ペイン）、`~`（ホーム）ほか。
- **標準（Finder 準拠・⌘ ベース）**: 矢印キー移動、`⌘C`/`⌘X`/`⌘V`、`Delete`/`⌘⌫`（ゴミ箱）、`F2`（リネーム）、`⌘⇧N`（新規フォルダ）、`⌘F`（フィルタ）、`⌘J`（検索）、`⌘⇧H`（ホーム）ほか

画面上のツールバー・右クリックメニューからもマウス操作できます。

## 既知の制約・注意
- **署名と権限（TCC）**: 未署名（ad-hoc 署名）のビルドは、ビルドのたびにファイルアクセス権限（デスクトップ/書類等）の許可が求められ直すことがあります
- **ホットキーの衝突**: `Ctrl+Space` は日本語入力の英かな切替と衝突するため既定ホットキーには使えません。

## データの保存場所
- 設定（ホットキー・キーマップ・ブックマーク・ホーム・透明度など）: アプリ設定ディレクトリの `config.json`
- 訪問履歴（frecency）: アプリ設定ディレクトリの `frecency.sqlite`

いずれもローカルに保存され、外部への送信は行いません。
ホーム配下のインデックスはメモリ上にのみ保持し、隠しファイル・`Library`・`.Trash` 等は除外します。
